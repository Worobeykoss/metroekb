# Метро Екатеринбург — живые поезда

Android-приложение: тёмная полупрозрачная поворачиваемая карта Екатеринбурга (MapLibre,
векторный тёмный стиль), поверх — линия метро (9 станций) и **живые поезда**, которые едут
между станциями в двух направлениях в реальном времени по расписанию с
[metro-ektb.ru](https://metro-ektb.ru/). По тапу на станцию — панель прибытий: по 2 поезда
в каждом направлении и «сколько прошло с последнего».

## Как это работает

- Расписание бандлится офлайн в `app/src/main/assets/schedule.json` (станции, координаты,
  времена прохода поездов). Генерируется скрапером `tools/scrape_schedule.py`.
- Направления: `to_botanicheskaya` — на юг (поезд идёт со стороны Проспекта Космонавтов),
  `to_prospekt_kosmonavtov` — на север. Конечные станции — по одному направлению.
- Ночные рейсы (00:xx) относятся к концу служебных суток — считаются «служебной минутой»
  (часы 0–2 → +24ч), см. `domain/MetroClock.kt`.
- Ядро `domain/TrainSimulator.kt` из одного расписания даёт:
  1. панель станции (2 ближайших поезда + «прошло N мин»);
  2. поезда «в пути» на перегонах — позиция = доля пройденного времени между временами на
     соседних станциях; поезд приходит на станцию ровно в момент из таблицы. У конечных нет
     таблицы прибытия — последний перегон достраивается по длительности из обратного направления;
  3. «личность» поезда `TrainRef` — по ней поезд находится на любом следующем перегоне
     (тап по поезду, слежение камерой, вид из кабины), прибытия для вспышек станций.
- Время везде примерное, шаг 30 с (`domain/ApproxEta.kt`): поезда приходят ±30 с от графика.

## Что умеет

- Поезда-капсулы с плашкой «~2½ мин» до следующей станции; вспышка станции при прибытии.
- Тап по поезду: куда едет, перегон, прогресс; «Следить» — камера ведёт поезд; «Из кабины» —
  вид из кабины (тоннель, платформа, скорость).
- «Успею?»: по времени пешком до ближайшей станции поезда, на которые не успеть, бледнеют,
  первый, на который успеваешь, подсвечен зелёным (и в окошке ближайшей станции).
- Предупреждение о последнем поезде (за 30 мин) в окошке ближайшей станции и в панели станции.
- Компас к ближайшему входу (тап по окошку ближайшей станции); входы видны на карте вблизи.
- Погода «наверху» в панели станции (Open-Meteo, без ключа).
- Пасхалка: ночью (01:00–05:30) по линии катается поезд-призрак. Днём — 5 тапов по плашке времени.
- Настоящая форма линии и тоннелей (OSM, `assets/geometry.json`): поезда едут по изгибам пути.
- Тепловой след за поездами (градиент по пройденному за ~40 с пути).
- Темы карты: тёмная, «чертёж», «ретро»; свои цвета поездов; альтернативные иконки (activity-alias).
- Окно станции с вкладками: «Поезда» (погода, загруженность по частоте поездов, последний поезд),
  «Схема» (выходы вдоль платформы по координатам входов OSM, какой вагон к какому выходу, ♿ входы),
  «Фото» (Wikimedia Commons, `assets/photos.json`), «Заметка» (свой текст и лучший вагон).
- Избранные станции (★), поиск станции или адреса (Nominatim), таблица времени в пути (из графика).
- Отсчёт до закрытия метро в плашке; умный темп ходьбы по GPS; офлайн-карта (MapLibre offline).
- Автопроверка графика раз в сутки: выходные с сайта применяются сами (`filesDir/schedule_override.json`),
  смена картинок будней — предупреждение; всё пишется в «Историю изменений».
- TalkBack: озвучка окон и кнопка «Все станции» (список со временем).
- Настройки и личные данные сохраняются (SharedPreferences).

## Сборка

Быстро: `build_apk.bat` кладёт `MetroEkb.apk` на рабочий стол (SDK — `E:\Android\Sdk`, см. `local.properties`).
Из-под CLI-агента Gradle нужно запускать без сэндбокса и с коротким TEMP, иначе падает на
«Unable to establish loopback connection». Или в Android Studio:

1. Открыть папку `E:\CODE\MetroEkb` в **Android Studio** (Gradle wrapper и зависимости
   подтянутся при первом Gradle Sync; SDK берётся из `local.properties`).
2. Запустить конфигурацию `app` на устройстве (Pixel 8) или эмуляторе. Нужен интернет —
   векторные тайлы карты грузятся онлайн (CARTO dark-matter, без ключа).

Требования: JDK 17 (`JAVA_HOME`), Android SDK 35, minSdk 26.

## Тесты

JVM-тесты ядра на реальных данных: `app/src/test/.../TrainSimulatorTest.kt`.
В Android Studio: правый клик по тесту → Run, или в терминале `./gradlew testDebugUnitTest`.
Ключевая проверка — пример: Уралмаш, выходные 12:00 → 5 и 6 минут.

## Данные

- Выходные: `python tools/scrape_schedule.py` — скрапит с сайта, перезаписывает `schedule.weekend`.
  ⚠️ Скрипт создаёт файл заново с пустым `weekday`, поэтому после него запускай `build_weekday.py`.
- Будни: `python tools/build_weekday.py` — заливает `schedule.weekday` (данные набраны со
  скриншотов официальных таблиц РАБОЧИХ ДНЕЙ; на сайте постранично публикуются только выходные).
- Проверить логику без Android: `python tools/reference_sim.py`.
- Входы в метро: `python tools/fetch_entrances.py` — из OpenStreetMap в `assets/entrances.json`.
- Форма линии: `python tools/fetch_geometry.py` — из OpenStreetMap в `assets/geometry.json`.
- Фото станций: `python tools/fetch_photos.py` — Wikidata/Commons в `assets/photos.json` (только ссылки и подписи).
- `assets/schedule_meta.json` — страницы станций и даты картинок будней для автопроверки.
- Оба раздела заполнены по всем 9 станциям. Проверено на примерах: выходные, Уралмаш 12:00 → 5/6 мин;
  будни, Уралмаш 19:45 → 4/3 мин.
